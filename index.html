收到一条消息后，按这里选的目标转发。当前状态：加载中…

钉钉

在钉钉群里添加自定义机器人后，把 webhook 地址贴进来。
只在机器人开启了“加签”安全设置时才填。留空表示保持原来的值。

QQ 官方机器人

在 QQ 开放平台（q.qq.com）应用管理里查看。留空表示保持原来的值。

接收方（可多个）

勾上的都会收到：群聊和私聊可以同时发，私聊也可以加好几个人。只想发一个就只勾一个。

找不到 openid？让机器人自己抓

QQ 不提供“QQ 号查 openid”的办法，openid 只在机器人收到消息时出现。所以：先在上面填好 AppID 和 AppSecret 并保存，然后用 QQ 给机器人发一条消息（私聊它，或把它拉进群里发一条），openid 就会出现在这里，点“添加为接收方”就能直接加到上面。

监听状态：加载中…
可以自己改。测试会发给上面所有勾上的接收方。

怎么用

别的服务想发消息时，往这个地址 POST 一条 JSON：

POST 

{
  "text": "有人按门铃了",
  "title": "门口提醒"
}

title 可不填。发给所有勾上的接收方，返回每家的结果：{"ok": true, "results": [{"target": "私聊 Alice", "ok": true, "detail": "..."}]}。
